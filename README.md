# Velizha Ayu Retnosari: portfolio

A one-page portfolio for UI/UX designer and frontend developer roles. It is a plain static site: one `index.html`, one `img/` folder, no build step and no dependencies.

## Run it locally

Open `index.html` in a browser. The only outside request is the Google Fonts stylesheet (Plus Jakarta Sans and DM Sans).

## Deploy

Any static host works. On Vercel, import this repository, set the framework preset to **Other**, and leave the build command and output directory empty.

## What is inside

- **Design projects:** Bhumi, Spotify Music App Redesign (concept), Sweetheart, Selera Hanani.
- **Frontend projects:** Branch Delivery System, Branch Delivery System Revamp (React 19), myBCA Syariah Bisnis, eCRF, Clinic Booking Website, EMR, ArsipSehat Backoffice. These are screenshots from test environments with sample data. The source code is no longer available.
